# 03 — Sistema educacional

## Objetivo

Ensinar programação dentro de Princess of the Frontier por meio de missões e desafios que controlam robôs, resolvem problemas e demonstram competências.

## Progressão de conteúdo

A progressão é organizada por competências, começando em lógica e algoritmos e avançando para programação textual, estruturas de dados e automação.

## Interface de programação

- A programação por blocos faz parte da experiência planejada.
- Em dispositivos móveis, o editor deverá usar uma interface dedicada, em tela cheia, com blocos operáveis por toque e teclado adaptado para código textual.
- A interface desktop e o formato exato de armazenamento dos programas precisam ser definidos em uma especificação funcional.
- Os algoritmos dos robôs precisam ser executados de forma controlada, sem acesso arbitrário ao sistema ou à rede.

## Avaliação

A avaliação de código deverá considerar:
1. testes automatizados;
2. correção lógica;
3. eficiência;
4. cumprimento dos objetivos da missão.

## Orientação ao estudante

Quando o código falhar, o sistema apresentará dicas progressivas, explicações e exemplos sem entregar imediatamente a solução completa.

## Progresso educacional

Dashboard do jogador com:
- competências;
- evolução histórica;
- desempenho nas avaliações;
- recomendações de estudo.

## Conquistas e certificados

O jogo terá medalhas e títulos internos e certificados digitais emitidos pelo própriPrincess of the Frontier após a conclusão de trilhas educacionais. Esses certificados devem ser identificados como emitidos pelo jogo, sem sugerir acreditação externa que não exista.

## Critérios de aceitação educacional do MVP

- O jogador recebe uma missão de programação.
- O editor permite criar e executar um algoritmo.
- O sistema testa o algoritmo contra casos predefinidos.
- O jogador recebe feedback útil em caso de erro.
- O resultado é salvo e influencia o progresso educacional.
- O servidor valida a conclusão da missão.
